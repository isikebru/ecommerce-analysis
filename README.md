# 📊 E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data using Python and basic data analysis techniques.

## 🎯 Objectives

* Calculate total revenue
* Identify highest revenue orders
* Perform product-level revenue analysis
* Find best-performing products

## 🛠️ Tools & Technologies

* Python
* Jupyter Notebook
